\chapter{What the Software Now Covers}

\app{} was originally a two-group calculator. Version 2.0 extends the software in three directions:

\begin{itemize}
  \item different \term{research paths};
  \item recommended-value checking with explicit override;
  \item an \term{inverse workflow} for evaluating achieved results.
\end{itemize}

\begin{conceptbox}{Why the first wizard question changed}
In version 2.0, the first question is no longer the outcome type. It is the research path. This matches the real logic of research planning: the same variable, such as effect size, means different things in different designs.
\end{conceptbox}

\chapter{Choosing the Research Path}

\section{Two independent groups}

Use this path when one group receives the intervention and another group does not. The central claim is about a difference between groups.

\subsection*{Worked scenario}
A researcher in educational games wants to verify whether using the game Uno helps children learn the concepts of greater-than and less-than. The intervention group plays Uno with guided prompts and then receives a short lesson. The control group receives only the short lesson. Both groups complete a final test.

\subsection*{Why this path fits}
The intervention is not defined as change inside the same participant over time. The main claim is whether the intervention group differs from the control group at the end of the activity sequence.

\section{Pre-test/post-test with control group}

Use this path when both groups are measured before and after. This is useful when baseline differences matter and when the researcher wants the pre-test to improve precision.

\subsection*{Worked scenario}
A researcher in educational games wants a stronger design than post-test only. All children complete a pre-test on greater-than and less-than. The intervention group then plays Uno and receives a short lesson. The control group receives only the lesson. Both groups complete the same post-test.

\subsection*{Why this path fits}
The software treats the pre-test as a precision-improving measurement and asks for the expected correlation between pre-test and post-test. Higher correlation usually means a more efficient design.

\begin{statbox}{What the pre/post correlation does}
When pre-test and post-test are moderately or strongly correlated, baseline information helps reduce unexplained variability. The version 2.0 implementation uses an approximate ANCOVA-style precision gain based on the factor \((1-r^2)\), where \(r\) is the pre/post correlation.
\end{statbox}

\section{One-group pre-test/post-test}

Use this path when the same participants are measured before and after and there is no control group.

\subsection*{Worked scenario}
A researcher wants an early pilot before attempting a controlled trial. The same children complete a pre-test, participate in a guided Uno session, and then complete a post-test. Final adherence is defined as completing both tests.

\subsection*{Why this path fits}
The design is centered on change within the same participants rather than comparison against a separate group.

\begin{warningbox}{What this path cannot establish strongly}
Without a control group, observed improvement may reflect practice effects, history, maturation, or ordinary instruction rather than the intervention itself. This path is useful for pilots, feasibility work, and early signal detection, but not as strong causal evidence.
\end{warningbox}

\chapter{Understanding Effect Size Better}

\section{Why effect size is difficult}

Effect size is difficult because it must connect statistics to a real decision. The researcher should not ask only, ``What can I afford to detect?'' The better question is, ``What is the smallest effect that would matter enough to justify adopting the intervention?''

\section{Effect size in a post-test-only two-group study}

Suppose a post-test has a pooled standard deviation of 10 points. If a 5-point improvement would justify using the game-based intervention, then:

\[
d = \frac{5}{10} = 0.5.
\]

This is a traditional medium effect in Cohen's language \parencite{cohen1988power}, but what matters most is the practical meaning of the 5-point gain.

\section{Effect size in pre-test/post-test with control}

In this design, the important effect is often the difference in gain. Imagine that both groups start at similar pre-test scores. If the intervention group improves enough after Uno and the control group improves less after lesson only, the researcher wants the study to detect that meaningful difference in change.

The entered \field{effect_size_d} should therefore reflect the smallest meaningful standardized difference in gain.

\section{Effect size in one-group pre-test/post-test}

In a one-group pre/post design, the effect is the standardized change in the same participants. This can be useful for early pilots and feasibility checks.

\begin{warningbox}{Interpretation warning}
A one-group pre/post effect size can describe how much change was observed, but not by itself why that change happened.
\end{warningbox}

\section{Effect size in opinion or usability studies}

Sometimes the researcher has only a post-use questionnaire. In that case, the same logic still applies. If a 0.4-point difference on a 1-to-5 satisfaction scale would justify changing a game tutorial, and the expected pooled standard deviation is 0.8, then:

\[
d = \frac{0.4}{0.8} = 0.5.
\]

\chapter{Run Type: Planning or Evaluating}

\section{Planning the sample}

The planning workflow estimates:

\begin{itemize}
  \item initial valid analyzable cases;
  \item valid cases after design correction;
  \item participants who must start;
  \item participants who must be invited.
\end{itemize}

This separation is especially important in pre-test/post-test studies because a participant should not count as complete unless the required measurement points are complete.

\section{Evaluating the achieved result}

The inverse workflow asks the user for the achieved sample and the observed effect. It then estimates an approximate:

\begin{itemize}
  \item z statistic;
  \item p-value;
  \item achieved power for the observed effect.
\end{itemize}

\subsection*{Worked inverse scenario}
A one-group Uno pilot collected 28 children who completed both tests. The observed standardized change was 0.35. The researcher wants to know what that implies.

\subsection*{Why this matters}
If the desired effect was not found, the researcher should still report the effect actually observed and what the achieved sample was able to show about it.

\chapter{Worked Examples}

\section{Uno with control, post-test comparison}

A researcher in educational games wants to verify whether the use of Uno helps children understand greater-than and less-than. The intervention group plays Uno with guided prompts and then receives a short lesson. The control group receives only the lesson. The main comparison is the final test.

Recommended wizard path:

\begin{itemize}
  \item research path: two independent groups;
  \item run type: plan required sample;
  \item outcome: continuous;
  \item effect size: for example, \(d=0.5\) if a 5-point gain on a 10-point spread would justify adopting the intervention.
\end{itemize}

\section{Uno with pre-test/post-test and control}

A researcher wants a stronger design. Both groups complete a pre-test. The intervention group plays Uno and receives a short lesson. The control group receives the lesson only. Both groups complete the same post-test. The researcher expects a moderate pre/post correlation, such as 0.60, and wants to detect a meaningful difference in gain.

Recommended wizard path:

\begin{itemize}
  \item research path: pre-test/post-test with control group;
  \item run type: plan required sample;
  \item outcome: continuous;
  \item effect size: meaningful standardized difference in gain;
  \item pre/post correlation: use pilot data when possible, otherwise a reasoned value such as 0.50 or 0.60.
\end{itemize}

\section{Uno with one group only}

A researcher cannot yet recruit a comparison group and wants a pilot. The same children complete a pre-test, play Uno in a guided session, and complete a post-test.

Recommended wizard path:

\begin{itemize}
  \item research path: one-group pre-test/post-test;
  \item run type: plan required sample;
  \item outcome: continuous;
  \item completion rate: define completion as finishing both tests.
\end{itemize}

\chapter{Suggestions Tab}

The new suggestions tab is a practical judgment layer. It is designed to translate methodological concerns into direct software feedback.

It can warn about:

\begin{itemize}
  \item a no-control-group design;
  \item low response, completion, or usable-data expectations;
  \item cluster inflation;
  \item out-of-range values that the user deliberately overrode;
  \item achieved results that remain underpowered.
\end{itemize}
